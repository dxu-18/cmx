Let $n \in \mathbb{Z}$.
We show that $3 \mid n^{3} - n$.
The following cases are exhaustive.

\begin{itemize}
  \item Case 1: Suppose $n \equiv 0 \pmod{3}$.
    Then $n^{3} - n \equiv 0 - 0 \equiv 0 \pmod{3}$.
  \item Case 2: Suppose $n \equiv 1 \pmod{3}$.
    Then $n^{3} - n \equiv 1 - 1 \equiv 0 \pmod{3}$.
  \item Case 3: Suppose $n \equiv 2 \pmod{3}$.
    Then $n^{3} - n \equiv 8 - 2 \equiv 0 \pmod{3}$.
\end{itemize}

In every exhaustive case, $n^{3} - n \equiv 0 \pmod{3}$, that is, $3 \mid n^{3} - n$. \hfill$\square$
