Let $k$ be an integer.
We show that $k^{2} - k$ is even.
We proceed by case analysis on $k$.

\begin{itemize}
  \item Case 1: Suppose $k$ is even.
    Then $k = 2m$ for some $m \in \mathbb{Z}$, so $k^{2} - k = 2m(2m - 1)$ is even.
  \item Case 2: Suppose $k$ is odd.
    Then $k - 1 = 2m$ for some $m \in \mathbb{Z}$, so $k^{2} - k = k(k - 1) = 2km$ is even.
\end{itemize}

Hence $k^{2} - k$ is even, as required. \hfill$\square$
