Let $A, B$ be subsets of a universe $U$.
We show that $(A \cup B)^{c} = A^{c} \cap B^{c}$.
For every $x \in U$, $x \in (A \cup B)^{c}$ if and only if $x \notin A \cup B$ if and only if $x \notin A$ and $x \notin B$.
This holds if and only if $x \in A^{c}$ and $x \in B^{c}$, that is, $x \in A^{c} \cap B^{c}$.
Hence $(A \cup B)^{c} = A^{c} \cap B^{c}$, as required. \hfill$\square$
