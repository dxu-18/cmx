We show that every nonempty finite set of reals has a maximum.
Assume for the sake of contradiction that the claim is false.
Let $S$ be a counterexample of smallest size.
Removing one element gives a smaller set with a maximum $m$, and then $\max(m, x)$ is a maximum of $S$.
This is a contradiction.
Hence every nonempty finite set of reals has a maximum, as required. \hfill$\square$
