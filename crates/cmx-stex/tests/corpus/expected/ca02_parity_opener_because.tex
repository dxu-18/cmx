Let $x \in \mathbb{Z}$.
We show that $x^{2} + x$ is even.
The following cases are exhaustive, because $x \in \mathbb{Z}$ is either even or odd.

\begin{itemize}
  \item Case 1: Suppose $x$ is odd.
    Then $x = 2k + 1$ for some $k \in \mathbb{Z}$, so $x^{2} + x = (2k + 1)(2k + 2) = 2(2k + 1)(k + 1)$.
  \item Case 2: Suppose $x$ is even.
    Then $x = 2k$ for some $k \in \mathbb{Z}$, so $x^{2} + x = 2k(2k + 1) = 2(k(2k + 1))$.
\end{itemize}

In all exhaustive cases, $x^{2} + x$ is even. \hfill$\square$
