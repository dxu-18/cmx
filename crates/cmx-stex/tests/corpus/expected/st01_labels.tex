\textit{Lemma.} If $n$ is even, then $n^{2}$ is even.

\textit{Proof.} Write $n = 2k$.
Then $n^{2} = 4k^{2}$.
Hence if $n$ is even, then $n^{2}$ is even, as required. \hfill$\square$

\textit{Proposition.} $\sqrt{4} = 2$.

\textit{Corollary.} $2$ is rational.

\textit{Observation.} $0$ is even.

\textit{Remark.} The converse also holds.
