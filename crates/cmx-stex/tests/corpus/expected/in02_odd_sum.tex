\textit{Theorem.} For every $n \in \mathbb{N}$, $\sum_{i=1}^{n} (2i - 1) = n^{2}$.

\textit{Proof.} We proceed by induction on $n$.

\textit{Base case} ($n = 0$). The empty sum is $0 = 0^{2}$.

\textit{Inductive step.} Suppose that $\sum_{i=1}^{k} (2i - 1) = k^{2}$.
The $(k + 1)$st odd number is $2(k + 1) - 1 = 2k + 1$, so the sum up to $k + 1$ is $k^{2} + 2k + 1 = (k + 1)^{2}$.
Hence for every $n \in \mathbb{N}$, $\sum_{i=1}^{n} (2i - 1) = n^{2}$, as required. \hfill$\square$
