Let $n \in \mathbb{Z}$.
We show that $n(n + 1)$ is even.

\begin{itemize}
  \item Case 1: Suppose $n$ is even.
    Then $n = 2m$ for some $m$, so $n(n + 1) = 2m(n + 1)$ is even.
  \item Case 2: Suppose $n$ is odd.
    Then $n + 1$ is even, so $n(n + 1)$ is even.
\end{itemize}

In both cases, $n(n + 1)$ is even. \hfill$\square$
