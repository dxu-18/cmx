Let $n \in \mathbb{Z}$.
We show that $n^{2} + n$ is even.

\begin{itemize}
  \item Case 1: Suppose $n$ is even.
    Then $n^{2} + n = n(n + 1)$ is even.
  \item Case 2: Suppose $n$ is odd.
    \begin{itemize}
      \item Case 2a: Suppose $n = 1$.
        Then $n^{2} + n = 2$.
      \item Case 2b: Suppose $n \neq 1$.
        Then $n + 1$ is even.
    \end{itemize}
\end{itemize}

In either case, $n^{2} + n$ is even. \hfill$\square$
