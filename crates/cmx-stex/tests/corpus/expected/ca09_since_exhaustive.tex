Let $a, b$ be real numbers.
We show that $\max(a, b) \geq \frac{a + b}{2}$.

\begin{itemize}
  \item Case 1: Suppose $a \geq b$.
    Then $\max(a, b) = a = \frac{a + a}{2} \geq \frac{a + b}{2}$.
  \item Case 2: Suppose $a < b$.
    Then $\max(a, b) = b = \frac{b + b}{2} > \frac{a + b}{2}$.
\end{itemize}

Since the cases are exhaustive, $\max(a, b) \geq \frac{a + b}{2}$. \hfill$\square$
