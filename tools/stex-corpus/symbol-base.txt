# Source for crates/cmx-stex/data/symbols.tsv (spec feature 12: "library of thousands of words to math
# symbols"). Expand with: `stex-corpus symbols --base symbol-base.txt > crates/cmx-stex/data/symbols.tsv`
#
#   kind<TAB>latex<TAB>words (|-separated)<TAB>negated latex (rel/arrow only, optional)
#
# A word starting with `+` is an English relation phrase and also yields "is W", "is not W" and
# "isn't W" (the last two map to the negated latex). Kinds:
#   greek const set   atoms               func   operator name, argument optional (`sin x`, `sin(x)`)
#   funcp             operator name that is also an English word: math only as `rank(A)`
#   rel arrow         relations           bin  multiplicative operator     add  additive operator
#   setop             ∪ ∩ ∖ △ level       div  fraction ("divided by")     post  postfix (`A complement`)
#   accent            `x hat` / `hat x` → \hat{x}          big  big operator (`bigoplus from i=1 to n`)
# Words that are common English with a non-mathematical meaning are deliberately left out of the
# rel/bin/arrow kinds ("between", "smile", "star" as an operator, ...).
