\textit{Theorem.} For every $n \geq 4$, $n^{2} \leq 2^{n}$.

\textit{Proof.} We proceed by induction on $n$.

\textit{Base case} ($n = 4$). $4^{2} = 16 = 2^{4}$.

\textit{Inductive step.} Suppose that $k^{2} \leq 2^{k}$ for some $k \geq 4$.
Then $(k + 1)^{2} = k^{2} + 2k + 1 \leq 2k^{2} \leq 2 \cdot 2^{k} = 2^{k + 1}$ since $2k + 1 \leq k^{2}$ for $k \geq 4$.
Hence for every $n \geq 4$, $n^{2} \leq 2^{n}$, as required. \hfill$\square$
