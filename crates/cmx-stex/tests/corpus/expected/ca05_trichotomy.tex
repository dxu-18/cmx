Let $x$ be a real number.
We show that $\lvert x \rvert \geq 0$.

\begin{itemize}
  \item Case 1: Suppose $x < 0$.
    Then $\lvert x \rvert = -x > 0$.
  \item Case 2: Suppose $x = 0$.
    Then $\lvert x \rvert = 0$.
  \item Case 3: Suppose $x > 0$.
    Then $\lvert x \rvert = x > 0$.
\end{itemize}

These cases are exhaustive by trichotomy.
In all exhaustive cases, $\lvert x \rvert \geq 0$ for every real $x$. \hfill$\square$
