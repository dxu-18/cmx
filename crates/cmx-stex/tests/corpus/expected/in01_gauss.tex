\textit{Theorem.} For every $n \in \mathbb{N}$, $\sum_{i=1}^{n} i = \frac{n(n + 1)}{2}$.

\textit{Proof.} We proceed by induction on $n$.

\textit{Base case} ($n = 0$). $\sum_{i=1}^{0} i = 0 = \frac{0(0 + 1)}{2}$.

\textit{Inductive step.} Suppose that $\sum_{i=1}^{k} i = \frac{k(k + 1)}{2}$.
Then $\sum_{i=1}^{k + 1} i = \frac{k(k + 1)}{2} + (k + 1) = \frac{(k + 1)(k + 2)}{2}$.
Hence for every $n \in \mathbb{N}$, $\sum_{i=1}^{n} i = \frac{n(n + 1)}{2}$, as required. \hfill$\square$
