\textit{Theorem.} There are infinitely many primes.

\textit{Proof.} Assume for the sake of contradiction that there are only finitely many primes, say $p_{1}, p_{2}, \ldots, p_{k}$.
Let $N = p_{1} \times p_{2} \times \cdots \times p_{k} + 1$.
Then $N > 1$, so $N$ has a prime divisor $q$.
Since $q$ is one of the $p_{i}$, $q \mid p_{1} p_{2} \cdots p_{k}$.
Thus $q \mid N - p_{1} p_{2} \cdots p_{k} = 1$, which is impossible since $q > 1$.
This is a contradiction.
Hence there are infinitely many primes, as required. \hfill$\square$
