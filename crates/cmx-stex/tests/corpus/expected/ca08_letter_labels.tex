Let $n$ be a positive integer.
We show that $2^{n} \geq n + 1$.

\begin{itemize}
  \item Case k: Suppose $n = 1$.
    Then $2^{1} = 2 = n + 1$.
  \item Case k: Suppose $n > 1$.
    Then $2^{n} = 2 \cdot 2^{n - 1} \geq 2n \geq n + 1$.
  \item Case x:
    The argument above covers every $n$.
\end{itemize}

Hence $2^{n} \geq n + 1$, as required. \hfill$\square$
