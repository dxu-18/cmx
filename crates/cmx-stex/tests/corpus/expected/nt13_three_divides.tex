\textit{Theorem.} For every $n \in \mathbb{N}$, $3 \mid n^{3} + 2n$.

\textit{Proof.} We proceed by induction on $n$.

\textit{Base case} ($n = 0$). $0^{3} + 2 \cdot 0 = 0$, which is divisible by $3$.

\textit{Inductive step.} Suppose that $3 \mid k^{3} + 2k$ for some $k \in \mathbb{N}$.
Then $(k + 1)^{3} + 2(k + 1) = (k^{3} + 2k) + 3(k^{2} + k + 1)$.
Both terms are divisible by $3$, so $3 \mid (k + 1)^{3} + 2(k + 1)$.
Hence for every $n \in \mathbb{N}$, $3 \mid n^{3} + 2n$, as required. \hfill$\square$
