We now give the classical argument, which goes back to the ancient Greeks and is remarkably short.
The key idea is that a number which is one more than a multiple of every prime cannot itself be divisible by any of those primes.
So if $p_{1}, \ldots, p_{k}$ were all the primes, then the number $p_{1} \cdots p_{k} + 1$ would have no prime factor at all, which is absurd.
