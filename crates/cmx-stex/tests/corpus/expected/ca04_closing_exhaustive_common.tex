Let $n \in \mathbb{Z}$.
We show that $n(n + 1)$ is even.

\begin{itemize}
  \item Case 1: Suppose $n = 2m$ for some $m \in \mathbb{Z}$.
    Then $n(n + 1) = 2m(2m + 1)$.
    Hence $n(n + 1)$ is even.
  \item Case 2: Suppose $n = 2m + 1$ for some $m \in \mathbb{Z}$.
    Then $n + 1 = 2(m + 1)$, so $n(n + 1) = 2n(m + 1)$.
    Hence $n(n + 1)$ is even.
\end{itemize}

These cases are exhaustive.
Hence $n(n + 1)$ is even, as required. \hfill$\square$
